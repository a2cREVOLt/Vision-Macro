# Vision Macro

Vision Macro is a Bee Swarm Simulator automation build maintained by **ghost**.
It combines Natro's established macro workflow with a Python token-detection
pattern powered by local ONNX models.

## Start

Run `START.bat`, configure a field under Gather, and choose `VisionTokens` as
the pattern. The Python worker starts only after normal field travel completes.

## Vision Work

- Vision modification, integration, and branding: **ghost**
- Python token detection and movement bridge
- Local token and sprinkler models
- Perspective-calibrated token movement
- Native Windows SendInput movement
